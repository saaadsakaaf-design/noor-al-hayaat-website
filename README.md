# Noor Al Hayaat Pharmaceutical Industries — New Website

This is the complete redesign prepared from the approved green / gold / white visual direction. Asset filenames have been corrected to match the actual image contents.

## Included
- New responsive React/Vite website
- Home, Products, Our Factory, About Us, Quality, Contact Us
- Supplied factory and medicine images in `public/assets`
- Final Noor Al Hayaat emblem
- Web3Forms contact submission preserved
- Mobile responsive navigation

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## GitHub
Replace the current project files with this package. The asset files are already inside `public/assets`, so they can be uploaded together with the source files.


### Corrected asset naming
The image files are named according to what they actually show. Factory images use `factory-*`; medicine pack images use `product-*`.
